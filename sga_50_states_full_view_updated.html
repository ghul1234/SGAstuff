Seed price is now in dollars — the actual entry price of the contract — compared directly against the price target (EOI × multiplier, also in dollars). Gain % = (Price Target − Seed) ÷ Seed. Leverage multiplies that gain directly (Gain × Leverage), same relationship used earlier: futures return = leverage × underlying % move. One flat seed price applies to every state here, so states with a higher price target (bigger EOI) show a bigger gain off the same seed — adjust seed per-state manually if you want each state normalized to its own starting discount instead.

Days to Fair Value — read this carefully: this is a modeling estimate, not a prediction. It reuses the daily price-limit convergence math from earlier (seed price walking up toward the target under a capped daily move), adjusted by a liquidity tier based on market cap: mega economies (>$1T GDP) get 60% of the stated daily limit (assumed deeper, slower-moving market), large ($200B-$1T) get 80%, mid-size ($50B-$200B) trade at the stated limit, small (<$50B) get 130% (assumed thinner float, so percentage moves happen faster — but also far more prone to gaps and failed fills, which this number does NOT capture). These liquidity-tier multipliers (0.6/0.8/1.0/1.3) are assumptions I set for this model, not derived from real trading data — no SGA has ever traded, so there is no real volatility or liquidity history to calibrate against.
